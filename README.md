# 复习清单

> 一个只在自己电脑上跑的复习清单：树形任务（周 → 学习单元 → 任务）+ AI 验收 + 间隔复习。

## 简介

- 数据全部放在本机 SQLite（`data/`），没有账号、没有云同步。
- 只有点「AI 验收 / AI 规划」时，当前任务、题目和你的回答才会发给 DeepSeek。
- 没有第三方依赖：Python 标准库 + 原生 HTML/CSS/JS，不用 `pip install`、不用建 venv、没有构建步骤。

## 功能

- **树形任务**：周 → 学习单元 → 任务；拖拽排序、移动、复制、批量编辑。
- **任务元数据**：优先级、截止日期、标签、预计耗时、备注、资料链接、周期规则。
- **AI 验收**（项目级开关）：AI 出 3 道题、一次一题，通过后进入实现阶段（可留空提交，或粘贴/上传代码）。
- **AI 帮我规划**：新建项目时按主题自动生成「周 → 学习单元 → 任务」。
- **间隔复习**（项目级开关）：完成任务自动排到次日；复习队列按到期/逾期评分重排；内置 Python 课程库（8 周 / 261 个知识点）。
- **复习加练**：任意知识点都能让 AI 现场出一道新题（先做题、AI 再批改并给示范解法），
  满意可以「收进题库」，之后和内置题一起参与复习轮换；临时加练不改动复习排期
- **今日工作台 + 收集箱**：逾期 / 今天到期 / 未来 7 天 / 今天要复习 / 收集箱一页看完，支持一句话快速记录。
- **全局搜索**、**最近**、**今日聚焦 / 随机复习 / 进度统计**。
- **撤销 / 重做**（Ctrl+Z / Ctrl+Shift+Z，刷新后仍保留最近几步）、**回收站**（单条 / 批量 / 整个项目恢复，默认留 7 天）。
- **导入 / 导出**：JSON（可再导入，导入前有差异预览）、Markdown、CSV。
- **备忘录**：独立小本子，支持置顶与全文搜索。
- **提醒**（页内提示 + 浏览器通知，只在页面开着时生效）、**项目模板**（内置两套结构，可从模板新建）。

## 快速开始

### 环境要求

- `python3` 3.10+（开发环境 3.14）
- 可选（开发/测试用）：`node`、Playwright
- 不需要数据库服务：SQLite 随 Python 标准库提供

### 安装

```bash
cd /home/lyh/todo_list
cp deepseek.env.example deepseek.env     # 只需一次，然后在里面填 DEEPSEEK_API_KEY
```

### 运行

```bash
./open-ai-list.sh                        # 启动本机服务并打开浏览器（token 用 URL 的 # 片段交付，不进访问日志）
TODO_NO_BROWSER=1 ./open-ai-list.sh      # 只启动服务，不自动开浏览器
./start-ai.sh                            # 前台运行，日志直接打在终端，Ctrl+C 退出
```

- 换端口：`TODO_AI_PORT=9000 ./open-ai-list.sh`
- 服务日志：`/tmp/todo-list-ai.log`（超过 1 MB 自动轮转）
- **关掉所有页面 5 分钟后服务会自己退出**，这是正常行为；下次运行脚本会重新拉起
- 不要直接双击 `index.html`：数据只能通过本机服务读写

## 使用

工作台的输入框支持一句话快速记录（有日期/标签等信息时会先弹预览让你确认）：

```text
明天复习 Python 装饰器 #Python !高 30分钟 @Python项目 每天
```

支持写法：`今天/明天/后天/大后天`、`周X / 下周X`、`N天后`、`M月D日`、`MM-DD`、`#标签`、`@项目`、
`!高 / !中 / !低`（或 `!!` `!1`~`!3`）、`30分钟` / `1.5小时`、`每天 / 每个工作日 / 每周X / 每月N日`。

**周期任务**：在任务详情里设置规则后，完成时会在同一位置生成下一次（日期顺延；设了 `until` 就到期停止），
复制优先级、标签、耗时、备注、链接，但不继承验收记录与复习安排。

## 配置

只改 `deepseek.env`（保存即生效，不用重启服务；同名系统环境变量优先）：

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | DeepSeek 密钥（不填只影响 AI 功能，其它功能照常可用） | 空 |
| `DEEPSEEK_FLASH_MODEL` | 快速验收用的模型 ID | `deepseek-v4-flash` |
| `DEEPSEEK_PRO_MODEL` | 深度验收用的模型 ID | `deepseek-v4-pro` |
| `DEEPSEEK_BASE_URL` | API 地址 | `https://api.deepseek.com` |
| `DEEPSEEK_API_URL` | 可选：直接指定完整 `/chat/completions` 地址 | 空 |
| `TODO_AI_PORT` | 本机服务端口 | `8765` |
| `TODO_IDLE_SHUTDOWN_SECONDS` | 页面全部关闭多久后服务自动退出（秒） | `300` |

`deepseek.env` 里是明文密钥：启动时若存在会自动 `chmod 600`；也可以自己执行一次 `chmod 600 deepseek.env`。

## 数据与备份

所有数据都在 `data/`：`todo.sqlite3`（项目 / 任务 / 完成状态 / AI 验收记录 / 逐题对话 / 复习进度）
与 `memo.sqlite3`（备忘录）。备份在 `data/backups/`。

- **自动快照**：每天首次启动存一份；导入、恢复、清空已完成、清空回收站之前也会各存一份。
  保留策略：最近 7 天全留 + 30 天内每天一份 + 90 天内每周一份，更早的自动删除。
- **恢复**：更多工具 → 数据管理 → 选中一份备份 → **恢复**（恢复前自动再存一份应急备份，失败自动回滚，成功后页面刷新）。
- **导出 / 导入项目**：**导出 JSON** 可在别的机器上用 **导入 JSON** 读回；导入前有差异预览，执行前自动快照。
- 数据库版本比程序新时会拒绝启动（避免降级写坏数据）；程序升级时会自动迁移，并留下 `before-migrate-*.sqlite3` 快照。
- 想直接拷贝这些数据库文件，请先关掉页面、等本机服务退出。

## 开发

```bash
./scripts/check.sh                      # 全部检查：语法 + 静态检查 + 全量测试 + 端到端 + 反向验证 + 行尾约定
./scripts/check.sh quick                # 快速档：跳过端到端与真浏览器
python3 -m unittest discover -s tests   # 用例（后端 / HTTP 层 / AI 层 / 前端脚本 / 端到端 / 浏览器）
python3 scripts/verify-tests-catch.py   # 反向验证：把关键修复改回旧行为，对应测试必须失败
./scripts/browser-test.sh               # 真浏览器流程（缺系统库时自动本地解包，不需要 sudo）
ruff check . && npx eslint .            # 静态检查（ruff / eslint）
```

测试一律使用临时目录里的数据库，**不会碰 `data/` 下的真实数据**；没装 node 或浏览器时相关用例自动跳过。
