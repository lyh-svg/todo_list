# 视觉方向 B：墨 + 荧光笔（设计说明）

日期：2026-09-19
状态：待用户确认（本轮只落地「复习队列 + 复习会话」两个界面，看效果后再决定是否铺开）
前置：P1 token 化已完成（单一 `:root`，72 个令牌，正文 0 个颜色字面值），本方向是**换令牌值 + 收口少数规则**，不改结构。

## 一、决策记录（用户逐条选定）

| 问题 | 结论 |
|---|---|
| 荧光笔代表什么 | **只标「正在学／该复习」的状态**。逾期、今天该复习的条目自动带笔触；复习通过或完成后笔触消失。纯样式，不加字段、不加接口。 |
| 纸的底色 | **真中性纸**：底 `#f4f4f2`（无蓝无黄）、卡 `#ffffff`、1px 细线分区、**所有 box-shadow 清零**（纸上没有浮起）、圆角收到 2–3px。 |
| 笔和主色 | **一支黄笔 + 墨黑主色**：荧光黄只做笔触；按钮／链接／焦点环全部墨黑；逾期用朱红墨字 + 1px 朱线，不用荧光。 |
| 字体 | **保持系统无衬线**，不加字体文件（本地离线应用）；只修字阶、字重，数字用 `tabular-nums`。 |
| 颜色体系 | **四色制**：纸、墨（3 级）、朱、荧光。删掉蓝／绿／紫／青／琥珀以及所有彩色底胶囊和蓝辉光阴影。 |
| 落地方式 | **先做两个界面看效果**（复习队列 + 复习会话），截图确认后再铺到其余 18 个场景。 |

## 三、笔触怎么做

不用图片、不用伪元素绝对定位（不干扰布局），只用一行渐变 + 切片克隆：

```css
background: linear-gradient(180deg,
    transparent 6%, var(--marker) 6%,
    var(--marker) 94%, transparent 94%);
box-decoration-break: clone;
-webkit-box-decoration-break: clone;
padding: 0 2px;
```

上下各留 6% 透明，得到"笔画没盖满行高"的手感；`box-decoration-break: clone` 保证换行后每一行都各自有笔触（像真的划过去）。

**笔触只落在短文本上**，不盖整行、不盖卡片：

- 复习队列：`.review-item:has(.review-tag.today) .review-item-text`、`:has(.review-tag.learning)`
- 复习会话：`#reviewQuestionPrompt` 的第一段（`> div:first-child`，即题干本身）
- 逾期不进荧光：`.review-item:has(.review-tag.overdue) .review-item-text` 用朱红字 + 1px 朱红下划线（"最急"用朱笔，不和荧光抢编码）
- 不笔触：路径面包屑、元信息、标签、备注、已完成项、AI 对话内容、备忘录（自由记录，不参与复习状态）

## 四、本轮改动清单（只这两个界面）

复习队列 `#reviewView`：

1. `.review-item-text` 改 `display: inline-block; max-width: 100%`（笔触只包住文字，不铺满整行），保留原有单行省略
2. 今天复习／学习中 → 荧光笔触；逾期 → 朱红字 + 朱红 1px 下划线
3. `.review-tag` 彩色底胶囊 → 1px 细框方角（今天=墨框、逾期=朱框、学习中=墨框），去掉所有底色
4. `.review-group-title` 下方加 1px 细线（纸张分组感），`.gcount` 由蓝改墨
5. `.review-item:hover` 墨色 3% 浅底（令牌改值即可）
6. 行操作按钮 hover：良好/简单=墨黑，困难=墨二级，重来=朱红（令牌改值即可）

复习会话 `#reviewSessionView`：

1. `.review-card` 加 `1px solid var(--rule)`，圆角 3px，去阴影
2. 题干文字段套笔触（当前正在复习的东西被"划"出来）
3. `.review-meta` / `#reviewSessionProgress` 的 ` · ` 分隔符去掉，改全角空格（`·` 是"AI 默认观感"清单里的元信息套式）

5. `.review-answer` 的虚线分隔 → 1px 细线；`.review-summary` 同卡片处理
6. 焦点环：`:focus-visible { outline: 2px solid var(--ink); outline-offset: 1px }`（替代蓝色 box-shadow 环）

队列行首的路径分隔符（`项目名 · 路径`）同步改全角空格。

## 七、首页设计（追加）

**Brief：** 给「复习清单」做一张好看的首页。这个应用的世界是纸、墨、荧光笔、打勾的清单、间隔复习的节奏。

**颜色（6 值）：** 纸 `#f4f4f2` / 白卡 `#ffffff` / 细线 `#e3e1db` / 墨 `#1f1c18`·`#4a4741`·`#6f6b64` / 朱 `#b3261e` / 荧光 `#fbf0a3`。

**字体：** 系统无衬线，不加字体文件；层级全靠字号 + 字重，数字用 `tabular-nums` 等宽，占比字号压到 20px。

**布局：**

```
┌──────────────────────────────────────────────────────────────┐
│ 复习清单                        今日工作台 最近 搜索 回收站 …  │  ← chrome 压成小字
├──────────────────────────────────────────────────────────────┤
│ 今日待复习 ▓1▓                        [ 开始今日复习 ]        │  ← 第一行：今天要做什么
├──────────────────────────────────────────────────────────────┤
│ ⌕ 搜索项目                                        全部项目 ▾  │  ← 细线，不用盒子
│ 输入新项目名称…            □AI验收 □AI规划 模板… [新建项目]  │
│ ⋯ 更多工具                                                   │
│ ┌────────────────────────────┐ ┌───────────────────────────┐ │
│ │▓Python 8周系统复习▓  44% ▂▂ │ │ 收藏箱              0% ▁▁ │ │  ← 有复习的项目标题带荧光笔
│ │ 理解原理 · 动手实现 …       │ │ 快速记录，之后再归类 …     │ │
│ └────────────────────────────┘ └───────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

对齐：整体左对齐；数字与右列指标右对齐；所有分隔用 1px 细线，不用卡片阴影。

**原则：**
1. 纸面第一行只回答一个问题——今天要复习什么，以及从哪开始。
2. 层级靠排版和细线表达，不靠色块、阴影、胶囊。
3. 唯一亮色（荧光黄）只标"现在要动手的事"；朱红只标"已经晚了的事"。
4. 一个意思只留一处标记（去掉与荧光笔重复的卡片书脊）。
5. 空态是邀请：没有要复习的项时，笔触消失、数字转墨灰，入口仍然在。

**自检（对照"AI 默认观感"清单）：** 无奶油底 + 衬线 + 陶土色组合；无全大写 eyebrow；无 ` · ` 元信息；无 SaaS 卡片套件（无阴影、圆角 2–3px、细线分层）；英雄区不是"大数字 + 小标签 + 渐变"的仪表盘默认式样，而是一句话加一个动作；无满屏入场动画。
